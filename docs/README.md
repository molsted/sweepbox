# Developer documentation

This folder is for people and AI agents working on Sweepbox's code. The user manual is in [user-docs/MANUAL.md](../user-docs/MANUAL.md). It is also published as the website's `docs.html`.

| Document | Read it when you need to know |
|---|---|
| [architecture.md](architecture.md) | How the pieces fit together: Core vs Desktop, how a run works, scheduling, settings, updates |
| [development.md](development.md) | How to build, run, test and debug. Code conventions, common changes, dependencies and lock files |
| [releasing.md](releasing.md) | Versioning, CI workflows, installers, signing, the in-app updater and the website |

Start with [AGENTS.md](../AGENTS.md) for the short rules that apply to every change.

When you change how something works, update the matching document in the same PR.
